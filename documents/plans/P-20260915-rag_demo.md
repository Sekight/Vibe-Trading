## 实现方案

工程结构（`E:\interview\rag-demo`）：

```
rag-demo/
├── pom.xml                     # Spring Boot 3.4.5 + Spring AI 1.0.0 GA + spring-ai-vector-store
├── README.md                   # 启动命令 + 演示问题脚本 + 技术说明（面试话术）
├── data/docs/                  # vibe-trading 核心 md 语料快照（从仓库拷贝，固定可复现）
└── src/main/
    ├── resources/
    │   ├── application.yml     # 真实模式：base-url/api-key 走环境变量，不入库
    │   ├── application-mock.yml# mock 模式：排除 openai 自动配置，本地向量
    │   └── static/index.html   # 极简聊天页（SSE 流式 + 来源列表）
    └── java/com/demo/rag/
        ├── RagDemoApplication.java
        ├── config/VectorStoreConfig.java   # SimpleVectorStore + JSON 持久化
        ├── config/MockAiConfig.java        # mock EmbeddingModel/ChatModel（@Primary）
        ├── ingest/MarkdownLoader.java      # md 按标题切分
        ├── ingest/IngestRunner.java        # 启动时切块+入库+持久化（幂等）
        └── controller/ChatController.java  # 检索 + 拼 prompt + SSE 流式回答 + 来源标注
```

链路与关键设计：

1. **语料准备**：把 vibe-trading 核心 md 复制到 `data/docs/` 做快照（固定版本，演示可复现，不依赖仓库被改动）。
2. **切块**：`MarkdownLoader` 按 markdown 标题（`##`/`###`）切分，超长节再用 `TokenTextSplitter`（chunkSize=600）二次切块；metadata 记录来源文件名 + 标题（回答引用的基础）。
3. **向量化入库**：embedding 用 OpenAI 兼容端点（`text-embedding-ada-002`，yml 可换）；`SimpleVectorStore`（spring-ai-vector-store 自带，内存 + JSON 持久化，无需外部向量库服务）；IngestRunner 启动时执行，向量库文件已存在则跳过（幂等）。
4. **检索**：问题 → `SearchRequest.builder().query().topK(4).similarityThreshold(0.5)` → 余弦相似度。
5. **生成**：`ChatClient.create(ChatModel).prompt().system(检索内容).user(问题).stream().content()` 流式；system prompt 约束"仅基于检索内容回答、标注来源、不知道就说不知道"（对应 AI-Agent 文档第 8 节防幻觉点）。
6. **可演示性**：SSE 事件流（先发 `source` 事件列出来源，再流式发 `answer`）；预置演示问题清单；mock 模式无 key 也能跑通全链路。

技术选型理由（面试能讲）：
- **Spring AI 1.0.0 GA**（用户拍板）：接口是当前主流 `ChatClient` / `EmbeddingModel` / `VectorStore` 命名，与面试认知一致，比 ai-job 的 0.8.x Client 命名好讲。配套 Spring Boot 3.4.5。
- **SimpleVectorStore**（用户约束"少拉新依赖"）：spring-ai-vector-store 自带，零外部服务，符合原计划"本地向量库"目标；面试延伸可讲"换 PgVector/Chroma/Milvus 接口不变"。
- sqlite-vec 被 Spring AI 官方排除（调研 1），不采用；Chroma 需额外起服务，SimpleVectorStore 更省事。
