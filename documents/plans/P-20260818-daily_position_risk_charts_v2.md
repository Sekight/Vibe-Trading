## 项目调研

- 组合级现状（V034/V035）：「持仓与风险」tab 已有两张组合级图——图 1「每日组合持仓」（收盘口径：毛/净/单边三线，取每自然日非夜盘最后一根 bar）、图 2「每天账户风险度」（峰值口径：单边日峰值 + 100% 强平线）。数据在 digest（`daily_position` 收盘 / `daily_risk` 峰值），前端经 `/runs/{id}/analysis/charts` 获取。
- 单标的现状：**无**。`artifacts/positions.csv` 有每 bar 每 code 的目标权重（v437fixB：4 code × 6942 bar）；策略 `weight_groups` 已把伪单位归并为逻辑标的（TA0001-0004.ZCE → TA），V033/V034 的"单边"口径依赖该分组。
- 性能边界（v437fixB 实测估算）：单标的每日序列（2432 天 × 毛/净/单边）JSON ≈ 140KB/标的；100 标的全量 ≈ 14MB——**不得进 digest、不得一次全量返回**，必须按需加载（下拉框选标的 → API 现读 positions.csv 返回单标的序列，~140KB/次可接受）。
- API 现状：`/runs/{id}/analysis/charts` 返回组合级 payload（digest 驱动）；单标的需要**新增端点**（现读 positions.csv，不依赖 digest——digest 只存组合级）。
- 复用点：digest.py `daily_position_and_risk` 已有"按组算毛/净/单边 + 按天聚合（收盘/峰值）"的逻辑，可拆出**单组**版本（当前是跨组合计，需改为返回单组序列）。

## 需求目标

- 做什么：「持仓与风险」tab 新增**单标的每日持仓图**——下拉框选择标的（按 `weight_groups` 分组的逻辑标的，如 TA / RB / FG），显示该标的每日**毛 / 净 / 单边**（默认收盘口径，可切换峰值），多标的账户可逐标的观察"哪个标的贡献了多少持仓"。
- 范围 / 边界：
  - 只动分析层 API + 前端「持仓与风险」tab + 测试 + 文档；**不动**组合级两张图与 digest 结构。
  - 单标的数据**不写 digest**（按需加载，API 现读 positions.csv）；digest 保持组合级。
  - 标的列表按 `weight_groups` 分组（未声明分组的 code 各自成组）；伪单位（TA0001-0004）合并为 TA。
  - 口径默认**收盘**（与组合图 1 一致），提供**峰值**切换（数据计算便宜）；图 2 组合风险度保持峰值职责。
- 验收标准（待拍板后细化）：
  - 下拉框列出逻辑标的；选中 TA 显示 2432 天毛/净/单边三线（收盘口径），切换峰值后为日峰值；
  - 多标的合成 run：每个标的独立序列、互不混算（RB 多 + TA 空 + FG 多时各自毛/净/单边正确）；
  - 无 weight_groups 的 run：按原始 code 分组（每 code 一组）；
  - 单标的序列加载与组合级一致快（~140KB/次）；无持仓 run 不崩。

## 风险 / 注意

- 单标的序列不得进 digest/全量响应（100 标的 ≈ 14MB，V034 已实测）；API 现读 positions.csv 按需返回（~140KB/标的/次）。
- 收盘/峰值双口径与组合级保持一致（收盘=非夜盘最后一根、峰值=当日 max 含夜盘），避免同指标两套口径。

- 单组聚合与 digest 组合级聚合口径必须一致——抽取共享函数防漂移。
