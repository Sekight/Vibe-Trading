# 趋势强度过滤规则

> 沉淀日期：2026-08-16（V3.52 策略优化验证）
> 类型：入场状态过滤规则（regime filter），非收益预测因子
> 适用范围：国内商品期货 15m 多空策略

## 1. 定义

**入场前要求信号 bar 的趋势强度 ≥ 60，且趋势方向与持仓方向一致，否则不开仓。**

趋势强度（0-100）口径：

- **方向打分**：均线排列 ±2（`close > MA5 > MA10 > MA20` 多头排列，反之空头）、MACD ±1.5（金叉/死叉）、BOLL ±1（上/下半区及触带）、SAR ±1；总分 ≥ 2 判上涨、≤ -2 判下跌、-2~2 判震荡。
- **强度合成**：震荡方向直接记 **40** 分；非震荡 = 基准 50 + 均线排列 15 + MACD 动能 15（零上金叉 / 零下死叉）+ 布林触带 10 + SAR 方向 10 + 偏离 MA20 最多 10，封顶 100。
- **参数**：MA 5/10/20、MACD 12/26/9、BOLL 20±2σ（ddof=1）、SAR step 0.02 / max 0.2。

两个可操作的事实：

1. 打分结构使强度值要么是 40（震荡）、要么 60+（趋势），41-59 区间几乎不存在——**"≥60"实际等价于"非震荡才入场"**。
2. 方向对齐条件（多单=上涨、空单=下跌）：在"close 穿越中轨 + MACD 红/绿柱"这类入场条件下会被数学蕴含（方向打分必然达标），对该类策略是冗余条件；对不含此类限制的策略则是真实过滤。

## 2. 适用场景

- **均值回归 / 触轨反弹类策略**：此类策略在震荡市里反复止损、磨损严重，该过滤能排除震荡状态——这是本规则的主要价值场景。
- **入场 setup 只在趋势状态下有效的策略**：趋势跟踪、动量、回调顺趋势入场均适用。
- **机制定位（重要）**：它是"状态过滤规则"（排除失效环境），**不是收益预测因子**——独立分组检验显示趋势强度对顺趋势方向未来收益的 IC≈0、20 根 horizon 上甚至负相关。因此它适合作为**风控纪律叠加在已有策略上**，不适合作为独立的选标的/选时机预测源。
- **不适用**：已有波动率/状态过滤的策略（叠加冗余）、纯高频。

## 3. 效果

**加规则后相对"未加过滤"的对比效果：**

| 验证场景 | 交易策略 | 过滤效果（对比未加过滤） |
|---|---|---|
| 螺纹钢 主窗口（2022-09 ~ 2025-09） | 均值回归 · 布林触轨反弹多空 | 收益相对提升约 231%；最大回撤收窄约 68%；Sharpe 相对提升约 266% |
| 螺纹钢 全窗口（2020-01 ~ 2025-09） | 均值回归 · 布林触轨反弹多空 | 绝对收益提升约 +27.6pp（由基本打平转正） |
| 螺纹钢 亏损窗口（2025-08 ~ 2026-08） | 均值回归 · 布林触轨反弹多空 | 亏损减少约 64% |
| 玻璃（2022-04 ~ 2025-03） | 均值回归 · 布林触轨反弹多空 | 亏损减少约 61% |
| 菜粕（2023-08 ~ 2026-08） | 均值回归 · 布林触轨反弹多空 | 亏损减少约 99%（基本转平） |

**机制**：过滤砍掉的主要是震荡市交易（各窗口交易次数减少约 55%~64%，手续费同步下降）；这些交易是未加过滤时的净亏损来源（单品种窗口内 46 笔震荡单净亏约 2 万，其中 32 笔震荡空单是主要出血点）——它们在震荡市反复止损、磨损收益，加规则后不再发生。

**边界（务必知悉）**：

- 它是**减亏/风控规则，不是收益预测因子**——独立五分组检验显示强度对未来顺趋势收益无预测力（IC≈0，长 horizon 负相关）；它的价值是"避开失效环境"，不是"预测赚钱行情"。
- **效果上限是"减亏/转平"**：在本身能盈利的窗口（螺纹钢主窗口）放大收益，在亏损品种（玻璃/菜粕）只能显著减亏、不能扭亏。
- 阈值 60 为样本内选择（恰好落在 41-59 空档，未做样本外调参）。

## 5. 参考代码

强度与趋势方向计算（与策略实际使用口径一致，pandas/numpy；全部只用 bar i 及之前的数据，无未来函数）：

```python
# ---- 指标（后视）----
ma5 = close.rolling(5).mean(); ma10 = close.rolling(10).mean(); ma20 = close.rolling(20).mean()
ema12 = close.ewm(span=12, adjust=False).mean(); ema26 = close.ewm(span=26, adjust=False).mean()
dif = ema12 - ema26
dea = dif.ewm(span=9, adjust=False).mean()
hist = dif - dea
b_mid = close.rolling(20).mean(); b_std = close.rolling(20).std()  # ddof=1
b_up = b_mid + 2.0 * b_std; b_lo = b_mid - 2.0 * b_std
# SAR（Wilder 抛物线，step=0.02 / max=0.2）：从首根累计递归，sar[i] 只依赖 0..i；sdir[i] ∈ {1, -1}

# ---- 分类（逐 bar 布尔）----
ma_bull = (close > ma5) & (ma5 > ma10) & (ma10 > ma20)                       # 多头排列
ma_bear = (close < ma5) & (ma5 < ma10) & (ma10 < ma20)                       # 空头排列
macd_bull = (dif > dea) & (hist > 0)                                          # 金叉
macd_bear = (dif < dea) & (hist < 0)                                          # 死叉
macd_strong = ((dif > dea) & (hist > 0) & (dif > 0)) | ((dif < dea) & (hist < 0) & (dif < 0))  # 零上金叉/零下死叉
boll_band = (close >= b_up) | (close <= b_lo)                                 # 触带
boll_bull = (close > b_mid) | (close >= b_up)
boll_bear = (close < b_mid) | (close <= b_lo)

# ---- 方向打分：MA ±2、MACD ±1.5、BOLL ±1、SAR ±1 ----
dir_score = (2.0 * ma_bull - 2.0 * ma_bear
             + 1.5 * macd_bull - 1.5 * macd_bear
             + 1.0 * boll_bull - 1.0 * boll_bear
             + 1.0 * (sdir == 1) - 1.0 * (sdir == -1))

# ---- 趋势方向：>=2 上涨(1)、<=-2 下跌(-1)、其余震荡(0) ----
trend = np.where(dir_score >= 2.0, 1.0, np.where(dir_score <= -2.0, -1.0, 0.0))

# ---- 强度（0-100）：震荡锁 40；否则基准 50 + 加分项，封顶 100 ----
#    分值含义：
#      40        = 震荡（dir_score 落在 -2~2，无方向）。本实现中 41-59 几乎不出现，
#                  所以"≥60"实际等价于"非震荡才入场"。
#      60-79     = 趋势成立（中等/弱趋势）；入场阈值 60 取这一档的下限，
#                  策略实际成交的强度也大多集中在这一段（60-70）。
#      80-100    = 强趋势。注意：独立检验显示强度越高、未来顺趋势收益反而越差
#                  （高分常对应趋势末端），所以强度是"状态刻度"，不是"收益预测"。
sideways = (dir_score >= -2.0) & (dir_score <= 2.0)
dev = (close - ma20).abs() / ma20
dev_pts = np.where(np.isfinite(dev), np.minimum(np.floor(dev * 1000.0), 10.0), 0.0)
strength = (50.0 + 15.0 * (ma_bull | ma_bear) + 15.0 * macd_strong + 10.0 * boll_band
            + 10.0 * (sdir != 0) + dev_pts)
strength = np.where(sideways, 40.0, strength)
strength = np.clip(strength, 0.0, 100.0)
```

入场过滤（信号 bar j 上）：

```python
if trend[j] == direction_sign and strength[j] >= 60:
    # 允许入场；direction_sign：多单=1，空单=-1
    # 震荡时 strength 恒为 40，天然被挡；60 即"趋势成立"档的下限
```
