【指标参数】
BOLL(20, 2)：中轨=MA20，上轨=中轨+2*std，下轨=中轨-2*std
MACD(12, 26, 9)：柱状图=DIF-DEA，红柱=柱值>0
ATR(14)

【进场条件】（交易日 14:55 判断，尾盘集合竞价模拟为当日收盘价成交）
1. 反弹日：当日最低价触及或跌破布林下轨，且收盘价回到下轨上方。
2. 突破：自反弹日次日起 3 个交易日内（第 1/2/3 根K线），某日收盘价突破布林中轨且收盘价高于中轨；该日即为信号日。
3. MACD：信号日 MACD 柱为红（>0），且当前柱值 > 前一交易日柱值（逐根抬升）。
4. 突破、MACD两个条件在同一个信号日同时满足才进场；信号日涨幅 >= 9.9%（主板涨停）则跳过该笔，不自动顺延。
5. 成交：信号日收盘价成交；信号与成交同日，禁止使用未来数据。

【仓位（以损定量）】
1. 止损价 = 自反弹日（含）至信号日的区间最低价 low_min - ATR(14) * 0.3（ATR 取信号日值）。
2. 风险金额 = 初始本金 1,000,000 * 5% = 50,000 元（固定）。
3. 手数 = 向下取整到 100 股/手：floor(风险金额 / (进场价 - 止损价) / 100) * 100；止损距离 <= 0 或不足 1 手则放弃该笔，不自动顺延。
4. 仓位上限（按当前总权益）：单只持仓市值 <= 40%，组合总持仓市值 <= 80%；超限则向下缩减手数，缩减后不足 1 手则放弃该笔。
5. 同日多标的出信号：按标的列表顺序逐个尝试，达到总仓位上限后剩余信号放弃。

【出场】
1. 止损优先：持有期间任一交易日最低价 <= 止损价，当日收盘价出场；同一日同时触发止损与止盈时按止损执行。
2. 止盈：持有期间收盘价曾突破布林上轨之后，任一交易日最低价触及布林中轨，当日收盘价出场。
3. 若持有期间从未突破布林上轨，则一直持有直到止损出场（不设时间止损）。
4. 出场时布林上/中轨使用当日最新滚动值。

【回测设置】
1. 数据源：优先读取本地 data-bridge 中对应标的的日线数据；缺失时使用内置腾讯日线源，并在 run card 记录每只标的数据来源。
2. 交易成本：使用引擎默认 A 股成本；若无默认，用佣金万 2.5 最低 5 元、卖出印花税 0.05%、滑点 0.1%。
3. 输出：核心指标 total_return / annual_return / max_drawdown / sharpe / win_rate / trade_count / avg_position_weight / max_position_weight；交易明细含每笔入场/出场日期、价格、手数、持仓占比、止损价、盈亏。
4. 若规则自相矛盾或数据缺失，按本提示词明确表述执行，并在 run card 里说明，不要擅自改规则。
